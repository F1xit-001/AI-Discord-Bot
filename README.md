Just a fun small first project for me and my friends, An ai discord bot bot creating using discord py library.
Has a few useful command, Display Server Statistics/Roles, Request random gifs using Tenor API, As well as Restrict/De-restricting certain channels from the bots commands and also keep track of these channels in .json file
The bot can also interact with users using Llama 3.1 AI model and has a simple memory system to make it remember past conversations
I also added a command that generate images, using stable diffusion-XL, thought it would be fun as well
Included some minor things as well and QOL features
